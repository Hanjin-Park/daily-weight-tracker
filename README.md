# 🎯 하루 체중 관리 (Daily Weight Tracker)

매일의 체중을 기록하고 추이를 한눈에 확인할 수 있는 간단하고 깔끔한 웹 애플리케이션입니다.

## ✨ 주요 기능

- 📱 **일일 체중 기록**: 날짜별로 체중을 입력하고 관리
- 📊 **체중 추이 차트**: 라인 차트로 체중 변화 시각화
- 📈 **통계 정보**: 현재 체중, 최고/최저 체중, 변화량 표시
- 💾 **자동 저장**: 브라우저 LocalStorage에 자동 저장
- 📥 **CSV 내보내기**: 기록된 데이터를 CSV 파일로 다운로드
- 📝 **메모 기능**: 각 기록에 메모 추가 가능 (예: "아침 식전", "저녁 식후")
- 🗑️ **데이터 관리**: 개별 삭제 및 전체 삭제 기능

## 🚀 시작하기

### 온라인 접속

```
https://[username].github.io/daily-weight-tracker/
```

(username을 자신의 GitHub 사용자명으로 변경하세요)

### 로컬에서 실행

1. 저장소 클론:
```bash

cd daily-weight-tracker
```

2. 브라우저에서 `index.html` 열기:
   - 파일 탐색기에서 `index.html`을 더블클릭하거나
   - VS Code의 Live Server 확장 프로그램 사용

## 📋 사용 방법

### 체중 기록 추가
1. **날짜 선택**: 캘린더에서 날짜를 선택
2. **체중 입력**: 체중을 kg 단위로 입력 (소수점 가능)
3. **메모 입력** (선택): 아침/저녁 등 메모 추가
4. **추가 버튼** 클릭 또는 Enter 키 입력

### 차트 확인
- 자동으로 렌더링되는 라인 차트에서 체중 추이 확인
- 마우스를 올려 정확한 값 확인 가능

### 통계 보기
- **현재 체중**: 마지막 기록한 체중
- **최고 체중**: 가장 높았던 체중
- **최저 체중**: 가장 낮았던 체중
- **변화량**: 첫 기록 대비 현재 변화 (빨강: 증가, 초록: 감소)

### CSV 내보내기
1. **CSV 내보내기** 버튼 클릭
2. `weight-tracker-YYYY-MM-DD.csv` 파일이 자동으로 다운로드됨
3. Excel이나 Google Sheets에서 열어 분석 가능

### 데이터 관리
- **개별 삭제**: 테이블에서 각 행의 "삭제" 버튼 클릭
- **전체 삭제**: "모두 삭제" 버튼으로 모든 데이터 제거 (되돌릴 수 없음)

## 💾 데이터 저장

### 로컬 저장소
- 모든 데이터는 브라우저의 **LocalStorage**에 저장됩니다
- 같은 기기, 같은 브라우저에서만 접근 가능
- 브라우저 캐시 삭제 시 데이터가 사라질 수 있습니다

### 백업 권장사항
- 정기적으로 **CSV 파일**로 내보내기
- 중요한 데이터는 클라우드에 백업하기
